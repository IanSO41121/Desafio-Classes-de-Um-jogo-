O projeto consiste na criação de uma classe Heroi, contendo propriedades como nome, idade e tipo, além de um método atacar() responsável por definir o ataque de acordo com o tipo do herói.

Conceitos praticados:

Classes e objetos
constructor
Propriedades e métodos
this
Estruturas condicionais
switch/case
Arrays
Laço for...of
Criação e utilização de instâncias com new

O desafio simula a estrutura básica de personagens de um jogo, permitindo aplicar conceitos de lógica de programação em uma situação prática.
